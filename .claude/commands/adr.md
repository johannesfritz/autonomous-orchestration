Create an Architecture Decision Record for a significant technical decision.

1. Identify the decision to document
2. Determine which project's docs/adr/ folder to use
3. Use the write-adr skill to create the ADR
4. Follow MADR format with Context, Drivers, Options, Outcome
5. Update the ADR index in the project

Usage:
- /adr Why we chose SQLite over PostgreSQL for Stellaris
- /adr Authentication approach for Hotel de Ville API
